# Умный офис

## Цель проекта

Создать виртуальный прототип офиса с рабочей зоной, переговорной и серверной. В серверной датчик температуры `TEMP` контролирует нагрев, а вентилятор `FAN` автоматически включается при превышении заданного порога. С рабочего места администратора можно наблюдать за состоянием оборудования и управлять вентилятором вручную.

## Состав стенда

| Устройство | Роль |
| --- | --- |
| `WIN` | Рабочее место администратора, мониторинг состояния и ручное управление |
| `CTRL` | Контроллер и точка сбора/передачи команд управления |
| `IOT` | Node-RED: программные модели датчиков `TEMP`, `HUM`, вентилятора `FAN` и других IoT-устройств |
| `MON` | Сервис мониторинга доступности и состояния узлов |
| `DB` | Хранение данных прототипа |
| `Cisco RTR` | Маршрутизация между сетевыми сегментами |
| `Cisco SW` | Коммутация устройств внутри стенда |

## Виртуальная среда

Стенд собирается в GNS3. Cisco RTR и Cisco SW настраиваются через консоли устройств. Виртуальные машины `IOT`, `CTRL`, `MON` и `DB` работают под РЕД ОС 8, а `WIN` моделирует рабочее место администратора под Windows Server 2019. SSH и SCP используются только между машинами РЕД ОС внутри топологии.

## Артефакты

- `office-plan.drawio` — план помещения с зонами, мебелью, шкафами, датчиками, вентилятором и IoT-устройствами.
- `network-topology.drawio` — логическая схема сети.
- `addressing.csv` — таблица VLAN, подсетей, IP-адресов, шлюзов и портов.
- `journal.md` — журнал действий, проверок и результатов.
